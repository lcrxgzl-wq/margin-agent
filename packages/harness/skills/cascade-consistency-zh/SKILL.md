# 全文联动一致性

何时使用：用户改某一段（综述、理论、发现）后，摘要、引言、结论或其他章节可能口径不一致。

## 步骤

1. 先 `get_block` 读清目标段；选区内可先 `propose_block_edit`。
2. 必做：`get_document_outline`，再 `search_blocks`（主张关键词、术语、时期化、核心命题）。
3. 用 `offer_cascade` 列出最多 5 个相关 `blockId` + 一句理由；**不要**对选区外静默 propose。
4. 等人确认「一并改」后，再对确认集 `get_block` → `propose_*`（每轮最多 3 处联动）。
5. 用户说「仅本地」→ 结束联动，不再追问。

## 不做

- 不把全文塞进回复；不一次改整章。
- 不烧苏格拉底澄清预算做联动确认（联动是产品确认，不是追问）。
- 不编造文献；缺证据用占位。
