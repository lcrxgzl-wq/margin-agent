# 苏格拉底式修订（协作澄清）

何时使用：

- 用户要求重写/编辑某段，但目标、语气、证据边界或验收标准过糊；或
- 用户开启追问模式 / 说「先别改，问清楚」。

## 硬限制（必须遵守）

1. **同一改稿线程最多 3 轮追问**。宿主会注入「澄清预算 N/3」；已用尽时**禁止再问**，必须基于合理假设 `propose_*`，并一句话交代假设。
2. 每轮最多 1–2 个**尖锐、可回答**的问题；禁止空泛「你觉得呢」「还有吗」；禁止长篇说教。
3. 指令已经够具体（可写出可验收改动）→ **直接提案**，不要为了「显得严谨」而追问。
4. 用户说「改吧 / 可以改了 / 直接改 / 按这个改」→ 立即提案。
5. 选区「重写」快路径（宿主已启动扫描）不受本 skill 拦阻。

## 提问焦点（择要）

- 要改的是语气、结构、论证跳跃，还是证据缺口？
- 现象能否被观察/测量，而非口号。
- 相对既有文献推进了哪一步；缺证据就标「[需插入引文：…]」，不编造。
