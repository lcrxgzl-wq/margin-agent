# 论证修订（中文社科）

何时使用：用户要求重写/诊断某段论证，或指出逻辑跳跃、套话、材料与理论脱节。

## 步骤

1. 先用工具读清目标段落（及必要上下文），不要凭记忆改。
2. 标出：主张是什么、证据在哪、推理如何连接；缺哪一环就改哪一环。
3. 优先最小改动；`propose_block_edit` 的 `after` 为整块替换 Markdown；`rationale` 一句中文。
4. 不擅自扩写新主张或新数据；不确定处用侧注说明风险。

## 不做

- 不编造文献、访谈或统计数字。
- 不直接改文件定稿；只提案，等人 Accept。
