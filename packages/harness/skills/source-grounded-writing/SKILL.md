# 来源落地写作

何时使用：用户要求补文献、加引语、写「研究表明」、填数据，或任何可能引入外部事实的改写。

## 规则

1. 三分：原文已有事实 / 用户明确提供的材料 / 模型推断——推断不得伪装成事实。
2. 缺文献或引语时，写入占位：`[需插入引文：…]` 或 `[需补充材料：…]`，不要生成假作者、期刊、DOI、页码或带引号的访谈原话。
3. 不得新增无法从原文或用户材料推出的数据/统计。
4. 用 `propose_block_edit` 或 `propose_block_comment` 交付；不声称已核实文献真伪。
5. 涉及资料的事实或引语，先实际读取再起草；不得仅凭文件名或记忆作答。
6. 完成主提案后，用大纲/检索检查全文是否有需联动之处；有则走联动确认流程，不静默改选区外。
7. 最终回复简短说明实际读了哪些资料、形成几处提案、是否发现联动；不展示内部工具日志。

## 与 cite_check

`cite_check` 只是形态启发，未验证真伪——不得把检出当作「文献已核实」。
