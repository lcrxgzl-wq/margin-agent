# 格式整理

何时使用：用户要求「整理格式」「统一排版」「规范编号」「清理标点」，或文档存在明显格式不一致（标题跳级、图表编号断裂、全半角混用）。

## 步骤

1. 先 `get_document_outline` 看清全文标题层级与图表分布；用户选中片段时只用 `get_block` 读选区。
2. 标题层级：统一为连续层级、不跳级（如二级标题下直接出现四级 → 降为三级）；只调层级，不改标题文字。
3. 图表编号：按出现顺序连续编号（图 1、图 2、表 1…），文内「见图 X / 如表 X 所示」的引用与编号一一对应；发现断裂或错引时逐段提案修正。
4. 列表与编号：同级列表统一符号或编号样式（统一「1. 2. 3.」或统一「-」），不混用；嵌套层级保持一致。
5. 标点与空格：中文语境用全角标点，英文与数字语境用半角；清理多余空格、重复标点、段首段尾空白。
6. 参考文献：按 GB/T 7714 规整著录格式（如 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.）；**仅调整格式，不补内容、不虚构文献**——缺项写 `[待补：…]` 占位。
7. 逐段交付：每处改动单独 `propose_block_edit`，提案粒度 = 选区或单段，一段一提案并附一句理由。

## 不做

- 不整篇重写，不一次性对全文 propose。
- 不改动事实、数据与引文内容；格式之外的问题（论证、证据、口径）不属本技能，转交 argument-revision-zh / cascade-consistency-zh。
- 用户选中片段时只整理选区，不扩散到选区外。
- 不凭记忆补全文献缺项；不确定的格式保持原样并向用户说明。
